# Homebrew Tap for BetterBar

A custom Homebrew tap for installing [BetterBar](https://github.com/josmanvis/betterbar), a customizable brutalist dock alternative and status bar for macOS.

## Installation

### One-liner

```bash
brew install josmanvis/betterbar/betterbar
```

### Two-step

```bash
brew tap josmanvis/betterbar
brew install --cask betterbar
```

## Upgrade

```bash
brew upgrade --cask betterbar
```

## Permissions Notice

BetterBar requires **Accessibility** and **Screen Recording** permissions to manage window states and render live window previews. Grant these under:
`System Settings` → `Privacy & Security` → `Accessibility` / `Screen Recording`.
